## 维护约定

三份文档共同以《AI资讯平台定位》的完整讨论及 2026-09-20 的文档委托为依据。讨论中出现过的早期方案，以后续明确共识为准。品牌为 Less；Important OR Useful；Source / Evidence 独立构成 Quality Gate；Phase 1 先验证内部内容系统。

蓝图是术语与产品边界的主定义，手册是编辑规则的主定义，MVP 是本阶段范围与指标的主定义。发生冲突时回到相应主定义修订，并同步检查另外两份文档。更改原则需项目负责人确认；基于案例的操作规则调整由编辑负责人记录；实施计划由实施负责人更新。同一人可以兼任。

每份文件保留版本、更新时间、维护角色与变更记录。标题中的版本可递增，文件名保持稳定，便于持续引用。新增规则注明依据；新增量化目标注明是否暂定。示例和待验证假设不能当作已验证的产品结果。

本目录是新建的项目工作目录，不修改上级 `sources/` 内的同步参考资料。后续迁移到正式开发仓库时，应整体保留本目录和相对链接。
